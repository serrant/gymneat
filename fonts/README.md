# Fonts

Barlow and Barlow Condensed (© 2017 The Barlow Project Authors), licensed under the SIL Open Font License 1.1 — see `OFL.txt`.
They ship with the app so it never contacts a font server. Only the weights the app uses are included:

- Barlow-Regular.ttf, Barlow-Medium.ttf, Barlow-SemiBold.ttf
- BarlowCondensed-Medium.ttf, BarlowCondensed-SemiBold.ttf, BarlowCondensed-Bold.ttf

Source: Google Fonts (fonts.google.com/specimen/Barlow and /Barlow+Condensed).
