# Project structure

The app's code is at the project root and runs as is in a browser. `npm run sync` copies it into the Android project. Edit only the files at the root; the copies (`www/`, `android/app/src/main/assets/public/`) are generated.

## The app

```
index.html            page shell
css/styles.css        all styles; @font-face, then colour tokens (light + dark), the only source of colour
fonts/                Barlow + Barlow Condensed (.ttf) and their licence (OFL.txt), shipped with the app
js/main.js            entry: boot, hash routing (#training, #plan, #trends, #weight), event wiring
js/state.js           data model S, storage on the device (localStorage), read helpers, day rules (dayState, doneOn, sessionsOn)
js/session.js         running a session: set → rest → next set → finish
js/stats.js           trend calculations — pure functions, unit-tested
js/io.js              backup: export (share menu in the Android app), Copy JSON, import; loads the licence texts
js/device.js          beep, vibration, screen wake lock (all best-effort)
js/native.js          Android features through Capacitor (back button, rest notifications, vibration, file sharing); no-ops in a browser
js/actions.js         every tap: buttons carry data-a="<action>", handled in one map
js/version.js         VERSION (MAJOR.MINOR), the only place the version is set: shown in Trends → Data; the Android build derives versionName and versionCode from it
js/data/exercises.js  exercise library, defaults per type, trend metrics
js/data/figures.js    exercise figures: start/end poses per movement family, exercise → family map
js/lib/               generic helpers: dates.js, format.js (numbers, times), util.js (escaping, ids)
js/ui/hooks.js        shared UI state `ui`, render hooks, toast, ask (confirm dialog)
js/ui/render.js       draws the current tab (#app) and overlays (#layer)
js/ui/components.js   chart, steppers, small markup helpers
js/ui/icons.js        inline line icons for icon-only buttons
js/ui/figure.js       draws an exercise figure (SVG) and animates it between its two poses
js/ui/views/          one file per screen: training.js, plan.js (and the exercise picker), trends.js, weight.js,
                      run.js (session and summary), data.js (bottom of Trends), legal.js (Licences and Privacy sheets)
```

## Android

```
capacitor.config.json app ID, name, web folder, system bars, notification icon
scripts/copy-web.js   copies index.html, css, js, fonts, LICENSE.txt, THIRD-PARTY-NOTICES.txt and PRIVACY.md into www/ and adds Capacitor's core script
www/                  generated by `npm run sync`; never edit
android/              native Android project generated by Capacitor. Files changed by hand:
  app/src/main/AndroidManifest.xml          permissions (INTERNET removed on purpose)
  app/src/main/res/                         icons and splash (from store/make_icons.py), colours
  app/build.gradle                          reads versionName and versionCode from js/version.js
  gradle/wrapper/gradle-wrapper.properties  Gradle pinned to 9.5.1
  settings.gradle                           toolchain resolver for Java 21
node_modules/         Capacitor and its plugins, installed by `npm install`
package.json          scripts (start, test, sync, open) and the pinned Capacitor versions
```

## Assets, tests and docs

```
store/                Play Store images (make.py, light and -dark) and the app icon in every size (make_icons.py)
tests/                unit tests (`npm test`)
docs/data.md          what is stored on the device, the export format, how progress is measured
docs/tech.md          technologies and libraries, and what each is for
docs/project-structure.md  this file
README.md             what the app is, how to run it, privacy
CLAUDE.md             rules and pitfalls for AI assistants working on the code
LICENSE.txt           short Gymneat header, then the GPL-3.0 text unchanged
THIRD-PARTY-NOTICES.txt  copyright lines and licence texts (MIT, Apache 2.0) of the open-source parts the app ships
PRIVACY.md            the privacy policy (shown in the app; its GitHub address goes in the Play Console)
```
